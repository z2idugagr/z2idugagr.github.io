Le calculateur de devis (/quote/) vous permet de choisir un service, de saisir une quantité et de voir immédiatement une estimation. Le devis formel est confirmé après lecture de vos fichiers — et la première page d'essai est gratuite. Essayez d'abord, décidez ensuite.

Ce qu'il me faut pour votre devis

  • Le service souhaité : traduction / localisation anglais → chinois traditionnel (Taïwan), traduction chinois traditionnel (Taïwan) → anglais, révision chinois simplifié → chinois traditionnel (Taïwan), ou sous-titrage
  • Vos fichiers source ou un lien : pour Steam, le lien de la page de boutique ; le format de fichier est libre
  • La quantité : nombre de mots pour l'anglais, nombre de caractères pour le chinois, minutes pour le sous-titrage. Vous ne connaissez pas le nombre de mots ? Collez le fichier dans Word ou Google Docs : il s'affiche en bas à gauche
  • Votre délai souhaité : signalez l'urgence le cas échéant (livraison en 24 heures ou le week-end : +30 %)

Délais de réponse

  • Le devis formel vous est présenté comme un prix ferme accompagné d'une date de livraison, après lecture de vos fichiers. Le montant annoncé ne change pas en cours de travail.
  • L'extrait d'essai gratuit du pack Steam vous est renvoyé sous 24 heures.
  • Aucune information de paiement n'est requise pour l'essai gratuit.

Tarifs et minimums

Traduction anglais → chinois traditionnel (Taïwan) à partir de US$0.08 / mot (minimum US$30) / localisation à partir de US$0.08 / mot (minimum US$40) / chinois traditionnel (Taïwan) → anglais à partir de US$0.08 / caractère (minimum US$30) / révision chinois simplifié → chinois traditionnel (Taïwan) à partir de US$0.04 / caractère (minimum US$20) / sous-titrage US$6.00 / minute (minimum US$30).

Paiement

Une fois le devis confirmé, j'indique un seul moyen de paiement dans le devis lui-même — Wise ou PayPal pour les clients hors de Taïwan. Petits projets (moins de US$300 au total) : paiement intégral à l'avance, la planification commence à réception. Projets plus importants (US$300 et plus) : 50 % d'acompte au départ, le solde sous 7 jours après confirmation de la livraison. La page d'essai gratuite est gratuite — aucune information de paiement n'est requise à l'avance.
