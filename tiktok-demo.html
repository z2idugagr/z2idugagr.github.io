Hank Reels Uploader — TikTok Sandbox Demo

Sandbox demo only. This page posts a short video as an inbox draft to the connected TikTok account via the Content Posting API (video.upload scope). Nothing is published publicly. The client secret is never stored on this page.

Step 1 — Connect TikTok (Login Kit)

Sign in with the TikTok account added as a Sandbox target user (@oni.exe7) and authorize the user.info.basic,video.upload scopes.

Step 2 — Exchange the code for an access token

The exchange needs the client secret, so run this in a terminal (fill in the code from Step 1 and the sandbox client secret):

curl -X POST https://open.tiktokapis.com/v2/oauth/token/ \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "client_key=sbawh29cdai1tmeizv" \
  -d "client_secret=PASTE_SANDBOX_CLIENT_SECRET" \
  -d "code=PASTE_CODE_FROM_STEP_1" \
  -d "grant_type=authorization_code" \
  -d "redirect_uri=https://hankloc.com/tiktok-demo.html"

Step 3 — Upload a video to the TikTok inbox (draft)

After the upload, check the TikTok app inbox on @oni.exe7 — the video arrives as a draft to finish and post. Status is polled below.
