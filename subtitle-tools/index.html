How it works 用法

  • Paste or load a subtitle file — the format (SRT / VTT) is detected automatically.
  • Hit Convert & Check: you get the converted file plus a health report. Flagged cues keep their original timing line in the output, so nothing is silently changed.
  • Apply shift moves every valid cue by the amount you set — handy when a video got a new intro or a cut.
  • The check covers format-level problems only. Wording, line breaks and reading speed still need a human pass — see the localization services below.
