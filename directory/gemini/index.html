Conditions disclosure: AI/LLM engines received the corpus with one shared neutral prompt ('Translate into Traditional Chinese as used in Taiwan' plus fixed formatting instructions). Machine-translation engines received the source text directly, with no prompt. The groups were measured under different conditions; this disclosure travels with the scores wherever they appear.

Gemini is Google's large language model family, accessible through Google AI Studio and the Gemini API. Used as a translation engine, it takes natural-language instructions — target variety, glossary and tone — in the same call as the source text.

Strengths — from evidence & published facts

  • Zero simplified-character residue (0.00% of 381 CJK characters) and a perfect terminology record: 34 preferred renderings, 0 mainland variants
  • Only one wording flag in 24 segments — 手機號 in S3, a rule-list 'worth checking' flag (the fuller 手機號碼 is the more idiomatic form), not a script error

Watch-outs

  • This score belongs to the disclosed AI-group condition: an explicit prompt asked for Traditional Chinese as used in Taiwan. Machine-translation engines in the same run received no prompt — the conditions differ by design and are disclosed wherever scores appear
  • In two segments it paraphrased around the trap terms (M2 'quality' → 高音質； U5 → 高畫質）; paraphrases are scored as 'other' — neither rewarded nor penalized in the terminology metric

Best for

Teams already using LLM APIs who want translation quality that follows instructions (glossaries, tone) without a separate MT contract.
