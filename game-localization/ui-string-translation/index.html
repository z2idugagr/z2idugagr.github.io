遊戲 UI 字串翻譯：字數限制怎麼處理

Hank Chen ・ 2026 年 11 月 16 日 ・ 約 4 分鐘閱讀

遊戲 UI 翻譯最常出問題的不是英文看不懂，是翻完貼回介面才發現字塞不下、按鈕破版、變數被翻壞。UI 字串有自己的規矩，下面三點先搞懂。

▍重點 1：英文比中文長，字數要先算好

同一個意思，英文常常比中文長。「Settings」翻成「設定」沒問題，但「Are you sure you want to quit?」翻成「你確定要離開遊戲嗎？」就可能超出對話框。做法是翻之前先拿到字數限制或按鈕寬度，太長的句子換短的說法，意思不變、字變少。

▍重點 2：變數跟佔位符一個字都不能動

UI 字串裡常有 {player_name}、%d、{0} 這種佔位符，程式會在執行時把玩家名字、數字填進去。這些符號不能翻、不能刪、不能換位置，翻壞一個，遊戲可能直接報錯。交件前把全篇佔位符拉出來，逐個跟原文核對。

▍重點 3：按鈕、選單、提示訊息，語氣要一致

「確認」「取消」「返回」這種按鈕，全篇要用同一種說法；提示訊息的語氣也要統一，不能一下很正式、一下很口語。建議先做一張常用詞對照表，按鈕、選單、錯誤訊息分開列，翻的時候照表走。

▍遊戲 UI 翻譯要花多少錢

UI 字串按字計價，USD 0.08／字，先免費試譯 500 字。字串數量多或有大量重複字串時，先傳字串表確認，報價以實際要翻的字數計算。收費方式可以參考主站的英翻中翻譯收費怎麼算？一字多少錢才合理。UI 以外的劇情文本做法，可以看獨立遊戲翻譯怎麼做？在地化最常忽略的 3 件事。

一句話總結：UI 字串翻譯的重點不是翻得漂亮，是翻完能直接用——字塞得下、變數沒壞、語氣一致。
